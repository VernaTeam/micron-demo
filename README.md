# Micron Abzar Sanat website: demo

A clickable demo of the website being built for Micron Abzar Sanat (Mohammadi tool making,
Tehranpars, Tehran): custom cutting tools, regrinding, PCD and CBN work, and a tool shop with
filters, cart, wishlist and compare.

**This is a demo, not the live site.** It runs without a server, so placing an order,
signing in, tracking an order and the contact form only show a "demo" notice. Browsing,
filters, the cart, the wishlist and the compare list work, stored in the visitor's own browser.
Products and photos are samples until the workshop's own arrive.

Live: https://vernateam.github.io/micron-demo/
